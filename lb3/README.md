# Створення  мобільного застосунку за допомогою Kotlin.

1. Створіть простий блог. Користувач повинен мати можливість додавати, редагувати та видаляти пости.
2. Додайте можливість додавання нових статей та коментарів. Реалізуйте систему категорій для статей.
3. Додайте можливість авторизації користувачів. Реалізуйте систему пошуку та фільтрації статей.
4. Впроваджуйте  кешування  на  сервері  для  покращення  швидкодії. Реалізуйте кешування результатів запитів або інше кешування за необхідності.
