# Практичне заняття 3. Мобільна розробка на Android з Kotlin

1. Створіть новий проект на мові Kotlin у середовищі розробки Android Studio. Виведіть привітання на екрані за допомогою текстового елементу.
2. Створіть простий калькулятор, який дозволяє вводити два числа та робити операції `+`, `-`, `*`, `/`.
3. Створіть додаток для перегляду списку фільмів. Кожен фільм повинен включати ім'я, жанр та рейтинг.
4. Розробіть  додаток  для  відстеження  фітнес-активностей.  Додайте можливість запису тренувань, введення даних та виведення статистики.
